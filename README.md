## 🌟 Key Features

* **🖥️ Interactive Cyber Bit-Stream Canvas**: Hardware-accelerated 2D canvas with reactive particle grid, floating binary streams (`0` and `1`), and smooth mouse interactivity.
* **>_ Built-in Web Terminal CLI Simulator**: Fully interactive in-browser Linux-like terminal with command history, auto-completion, and live simulated diagnostics (`dex --status`, `devlens --audit`, `apppulse --telemetry`, `team`, `matrix`).
* **📦 Featured Systems Showcase**: Deep dives into flagship production repositories:
  * **[Open Android DeX](https://github.com/Bit-manipulators/open-android-dex)** (Flutter Desktop & GTK4 Linux Multi-Window Workstation)
  * **[DevLens](https://github.com/Bit-manipulators/DevLense)** (Zero-Trust Ephemeral Sandbox & On-Device AI Debugger)
  * **[AppPulse](https://github.com/Bit-manipulators/App_pulse)** (100% On-Device Deterministic Android 15 Vitality Manager)
* **⚡ Live GitHub Metrics Sync**: Automatically fetches and caches organization stars, forks, and repository statuses via GitHub API with offline graceful fallbacks.
* **🏛️ Radical Transparency Matrix**: Side-by-side architectural contrast between commercial deceptive cleaner scams and Bit Manipulators deterministic first-principles engineering.
* **📱 Ultra-Responsive & Zero-Build**: Built on clean HTML5, Tailwind CSS, and ES6 JavaScript. Deploys seamlessly to GitHub Pages with zero complex compilation steps.

## 🚀 Local Development & Preview

Because the site requires zero external build toolchains, you can preview it with any local HTTP server:

### Using Python:
```bash
# Clone the repository
git clone https://github.com/Bit-manipulators/Bit-manipulators.github.io.git
cd Bit-manipulators.github.io

# Start local server
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

### Using Node / npx:
```bash
npx serve .
```
